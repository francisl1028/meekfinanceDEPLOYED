      Gemini API Key

      Stored privately in your own Firestore — never in this file, never shared.

      How to get your own free Gemini API key
      1. Open aistudio.google.com/apikey in a new tab.
      2. Sign in with any Google account (a normal Gmail works). No credit card needed.
      3. Accept the terms if prompted, then click the blue “Create API key” button.
      4. Choose “Create API key in new project” (or pick an existing one).
      5. Your key appears in a box — click the copy icon next to it. It looks like AIza…
      6. Come back here and paste it into the Gemini API Key field above.
      7. Click Save Key. Open the Assistant tab and ask it anything about your money.

      Free tier: ~15 requests/min, 1,500 requests/day. More than enough for personal use. Keep the key private — anyone with it can use your quota.
